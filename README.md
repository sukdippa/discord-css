Hello, you can use this CSS with BetterDiscord or Vencord or whatever has custom CSS. It's a heavily modified [refact0r system 24](https://github.com/refact0r/system24) that kind of simulates transparency.

This is a mock Mac vibrancy style since true vibrancy (which Vencord does supports) can't account for multiple layers of background pixels against a transparent window.

Replace the picture with what you want. I took my wallpaper and did darken + blur.
